## Сценарий (проверен 08.11.2026 через публичный адрес Funnel, как Android-приложение)

Файлы: `backend/demo/procurement/`. Повторить проверку перед показом:

```
python demo/procurement/run_demo.py https://win-347ek05mdnv.tailf14622.ts.net tv320
python demo/procurement/run_demo.py https://win-347ek05mdnv.tailf14622.ts.net kn80
```

Результаты: `eval/results/demo_tv320.json|.xlsx`, `demo_kn80.json|.xlsx`. Скрипт завершится с кодом 1, если хоть один шаг не совпал.

### TV-320 (учебное руководство, станок вымышленный)

1. Загрузить `tv320_manual.pdf` → «Детали»: 9 из 9, количества верные, у каждой цитата со страницы.
2. Камера: `marking_6205.png` → `matched`, 6205-2RS (точный артикул) → пользователь подтверждает.
3. Прайс `real_prices_kz.csv` (настоящие цены industrialmotion.kz и bcindustry.kz от 08.11.2026).
4. Предложения:
   - 6203 → точное совпадение, 2 620 ₸;
   - 6205-2RS → в прайсе только 6205 (без уплотнений): показан как «похожий, проверьте совместимость», сам не выбирается.
5. «Проверить цену на сайте» для 6203 → `site_checked`, 2 620 ₸, время проверки.
6. Ведомость: 6203 × 2 = 5 240 ₸; остальные 8 позиций — «нет цены», об этом предупреждение. Excel: источник цены «проверено на сайте», время по Казахстану, совпадение «точный», наличие.

### KN-80 (учебный паспорт насоса)

Детали 8 из 8 с верными количествами. Ни одной из них нет в реальном прайсе — ведомость честно без цен. Фото маркировки для KN-80 нет.

### Что говорить на защите

- Документы учебные (сгенерированы для проверки, правильные ответы известны заранее). Цены — настоящие, с сайтов поставщиков.
- Похожий артикул не выдаётся за точный: 6205 ≠ 6205-2RS.
- Нерелевантный документ (железнодорожный билет) → «промышленные детали не найдены».

## Что требует интернета

| Часть | Без интернета |
|---|---|
| Телефон/сайт → backend | основной: `https://api.docmind.kz` (VPS, ноутбук не нужен); запасной: Funnel на ноутбуке |
| Ответы, детали, фото, проверка утверждений | нужен Gemini (Google); запасная модель Groq |
| Проверка цены на сайте | нужен сайт поставщика |
| OCR сканов, прайс из файла, ведомость, Excel | на сервере, без ИИ |

Телефону для показа нужен только мобильный интернет: backend на VPS не зависит от Wi-Fi на площадке.

## День защиты: что делать при сбое

| Что видно | Причина | Что делать (≤ 2 минуты) |
|---|---|---|
| «Server offline» в приложении | VPS недоступен или адрес приложения не в CORS | `curl https://api.docmind.kz/api/v1/health`. Если не отвечает: `ssh -i ~/.ssh/docmind_vps root@89.126.199.206 systemctl restart docmind-api`. Если отвечает, а приложение нет: новый адрес Preview не в CORS — добавить в `/etc/docmind/backend.env`, перезапустить |
| VPS не поднимается | сбой у Hoster.kz | переключиться на ноутбук: Preview с `VITE_API_BASE_URL` = адрес Funnel (тот же код, тот же CORS) |
| Ответ ИИ: «превышен лимит» (`RATE_LIMITED`) | кончилась минутная квота бесплатного Gemini (проверено: 8 человек одновременно → 1 отказ, Groq тоже 429) | подождать 30–60 с и повторить; **до защиты включить оплату Gemini** (ключ тот же); во время показа не запускать тесты |
| ИИ не отвечает совсем | Gemini и Groq недоступны | показать сохранённые результаты (`eval/results/demo_*.json`, `.xlsx`) и видео; без ИИ работают документ, OCR, прайс, ведомость и Excel |
| Сломалось после обновления | новая версия | откат: `ln -sfn /opt/docmind/releases/<прошлый коммит> /opt/docmind/app && systemctl restart docmind-api` (см. `DEPLOY.md`) |
| Ноутбук недоступен | — | ничего: основной backend на VPS, бот в Telegram не работает (он на ноутбуке) |
| Интернет на площадке плохой | — | показывать с телефона по мобильному интернету |
| Всё сломалось | — | видео полного сценария с телефона (снять заранее) |

Аварийный выключатель ИИ: `AI_EMERGENCY_STOP=1` в `/etc/docmind/backend.env` + перезапуск — ИИ-запросы получают 429, остальное работает.

## Старый план (ноутбук как основной backend)

1. Ноутбук на зарядке, сон отключён, Funnel `https://win-347ek05mdnv.tailf14622.ts.net`. Нюанс: в Chrome на самом
   ноутбуке (там стоит Tailscale) нужно разрешить сайту «доступ к локальной сети», иначе «Server offline».
2. Плохой интернет — раздать с телефона; адрес Funnel не меняется.
3. Funnel не отвечает — `tailscale funnel status`, перезапуск Tailscale; запасной Cloudflare quick tunnel с новым адресом.
4. Откат на стабильную сборку `ba8b4ed` — `C:\Users\user\wt\stable`.

## Постоянный адрес API (чтобы не пересобирать приложения)

- Адрес Funnel `https://win-347ek05mdnv.tailf14622.ts.net` постоянный: он не меняется при перезапуске backend, Tailscale,
  смене сети или после сна ноутбука. Меняется только при переименовании компьютера в Tailscale или выходе из tailnet.
- Меняется адрес только у запасного туннеля Cloudflare. Варианты без пересборки APK/PWA:
  1. **Адрес backend из файла конфигурации (рекомендую).** Приложение при старте читает маленький JSON с постоянного
     адреса (например, `https://doc-mind-ai-liart.vercel.app/backend.json` → `{"apiBaseUrl": "https://..."}`), а
     если файл недоступен — берёт встроенный `VITE_API_BASE_URL`. Сменить backend = поменять один файл на Vercel.
     Это работа frontend (Samir), backend и API не меняются.
  2. Прокси через Vercel (rewrites `/api/*` → backend): приложение ходит на адрес Vercel. Не проверено: лимиты Vercel
     на размер загрузки и время ответа для внешних rewrites; Preview-адреса закрыты Deployment Protection.
  3. Свой домен (VPS или именованный туннель Cloudflare) — постоянный `api.<домен>`; нужен купленный домен.

## Перед публичным тестом по QR (проверено 08.11.2026 на 8022)

- Лимиты: на сессию 12 AI-запросов/мин и 40 в сутки; на один IP 300 в сутки; на весь сервер 1000 в сутки. Загрузки
  6/мин, до 10 документов и 100 МБ на сессию, файл до 20 МБ. Новые сессии — 30/мин с одного IP.
  Funnel передаёт реальный IP (в базе разные клиенты), поэтому лимит на IP работает для каждого человека. Но на
  площадке все в одном Wi-Fi могут выходить с одного IP — тогда 300 в сутки на всех.
- Аварийный выключатель ИИ: перезапуск с `AI_EMERGENCY_STOP=1` — все AI-запросы получают 429, остальное работает.
- Ключ Gemini только на сервере (`backend/.env`, в git не попадает). Во всех ветках репозитория и их истории ключа нет;
  во frontend только `VITE_API_BASE_URL` и `VITE_TELEGRAM_BOT_URL`, а `deployEnv` запрещает секреты в `VITE_*`.
- Чужие данные по ID: вторая сессия получила 404 на документ, файл, страницу, текст, факты, детали, удаление,
  чат, сообщения, проверку утверждения, прайс; в своих списках чужого не видит; без токена — 401.
  Закупки (тоже вживую): чужие предложения, проверка цены на сайте по чужому offerId, ведомость и Excel по чужому
  документу, подтверждения фото, удаление чужого прайса — 404. Чужой offerId в ведомости своего документа даёт
  `offer_missing` без цены; к своему документу чужой прайс не подмешивается (0 предложений).
