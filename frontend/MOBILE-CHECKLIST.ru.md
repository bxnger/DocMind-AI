# DOCMIND INDUSTRY на Samsung: контрольный сценарий

Отмечайте каждый пункт: ✅ работает, ❌ не работает (скриншот и что ожидали), ⚠️ работает, но неудобно.

## 0. Сборка
После обновления ветки обязательно, иначе в APK не попадёт плагин клавиатуры:
```bash
cd ~/DocMind-AI/frontend
npm install
VITE_API_BASE_URL=https://win-347ek05mdnv.tailf14622.ts.net npm run build:mobile
cd android && ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
Если приложение уже было установлено, при первом запуске может остаться старый профиль: «Профиль → Пройти приветствие заново».

## 1. Запуск и приветствие
1. Верх приветствия не заходит под строку состояния, кнопка «Начать работу» не закрыта панелью навигации.
2. Смена языка RU / KZ / EN на первом экране сразу меняет тексты.
3. «Далее» → выберите «Инженер», введите организацию → «Начать работу» → на главной «Добрый день, <организация>».
4. «Профиль → Пройти приветствие заново → Пропустить» → «Добрый день, гость».

## 2. Нижняя навигация
1. Пять вкладок помещаются, подписи не обрезаны, активная выделена.
2. Кнопка «Назад» на главной сворачивает приложение. На других вкладках возвращает на предыдущий экран.

## 3. Документы
1. «Документы → Загрузить документ» открывает выбор файлов Android. PDF и DOCX загружаются, после загрузки панель «1 загрузка» исчезает сама.
2. Удаление документа: окно подтверждения, «Назад» закрывает окно.

## 4. Экран документа
1. Внизу четыре раздела: Документ, Ассистент, Детали, Ещё. Вкладок приложения на этом экране нет.
2. Переключайтесь между всеми четырьмя: ничего не перезагружается, позиция в PDF сохраняется.
3. «Ещё» открывает лист: Проверка, Карта, Факты, Режим, Удалить. «Назад» закрывает лист.
4. Состояние не сбрасывается: напишите черновик в чате → «Детали» → выберите предложение → «Ещё → Проверка» → напишите утверждение → вернитесь в каждый раздел. Черновики и выбор на месте.

## 5. Ассистент и клавиатура
1. Нажмите в поле ввода: клавиатура не закрывает поле, нижняя панель исчезает.
2. Закройте клавиатуру кнопкой «Назад»: нижняя панель возвращается.
3. Спросите: «Какой подшипник на валу II и сколько штук?». Ответ читается, цитаты компактные (2 строки).
4. Нажмите на цитату: открывается страница 2, место подсвечено. Кнопка возврата ведёт к ответу.
5. «Показать больше» у цитаты: видна полная цитата и кнопка «Копировать».

## 6. Детали, фото, закупка
1. «Детали»: сводка «Из документа / Нужна проверка / Подтверждено фото / Без предложений», кнопка «Далее».
2. «Проверка фото → Сфотографировать деталь» открывает камеру Samsung. Снимите маркировку, дождитесь результата. Подтверждение только по нажатию «Да, это эта деталь».
3. «Загрузить фото» открывает галерею.
4. Текст под кнопками говорит, что фото отправляется на сервер DOCMIND и в Google Gemini.
5. «Предложения»: детали без предложений собраны в свёрнутую группу.
6. «Ведомость → Экспорт XLSX» открывает меню «Поделиться». Сохраните в «Мои файлы», откройте в Excel или Google Таблицах, сравните с экраном. То же для CSV.

## 7. Связь
1. Включите режим полёта: вверху сообщение о нет связи и «Повторить», без адреса сервера.
2. Выключите режим полёта → «Повторить»: работа продолжается.

## 8. Темы и экраны
1. Светлая и тёмная тема: иконки строки состояния видны в обеих.
2. Поверните телефон: ничего не обрезается.
3. «Настройки → Экран → Масштаб шрифта» на максимум: подписи не накладываются.

# Демонстрационный сценарий (около 5 минут)

Учебный документ и подготовленные файлы помечены в интерфейсе. «Цена проверена на сайте» показывается только после настоящей проверки.

1. **Главная → «Посмотреть демонстрацию».** Загружается учебный паспорт станка ТВ-320 (`tv320_manual.pdf`) с пометкой «учебный». Появляется шаг «Детали».
2. **Детали:** 9 деталей, у каждой цитата и страница. Нажмите на `6205-2RS`: открывается страница 2 с подсветкой. Вернитесь.
3. **Ассистент:** «Какой подшипник на валу II и сколько штук?» → ответ с цитатой, переход к странице.
4. **Проверка фото → «Как в документе»** (`marking_6205.png`, нарисованная маркировка): «Как в документе» → «Да, это эта деталь». Затем «Похожая маркировка» (6205-2RSH): ИИ называет разницу, автоматического совпадения нет.
5. **Предложения → «Прайс поставщиков Казахстана (6203)»** (`real_prices_kz.csv`). У `6203` нажмите «Проверить цену на сайте»: появляется «Цена проверена на сайте поставщика» с датой. Откройте карточку товара.
6. «Выбрать точные совпадения» → **Ведомость**: «Промежуточная стоимость», детали без предложений не входят в сумму, DEMO-цен нет.
7. **Экспорт XLSX** → «Поделиться» → открыть файл, показать колонки «Источник цены», «Наличие», «Проверено (время Казахстана)».
8. **Ещё → Проверка:** «Подшипник 6205-2RS установлен в количестве 40 шт.» → «Противоречит документу» и цитата.

Не смешивайте в одной демонстрации прайс поставщиков и «Придуманные цены DEMO»: показывайте DEMO отдельно, если нужно.
